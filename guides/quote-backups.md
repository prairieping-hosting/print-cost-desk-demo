# Keeping offline quote records recoverable

Before clearing browser storage or moving to another computer, download a JSON backup of your browser quotes. Store it somewhere you can find without opening the quoting tool, and give it a name that identifies its contents.

Use CSV when you want to review quote rows. Keep JSON for recovery because it retains the browser backup structure.

Test restoration in a separate browser profile before relying on the backup. Compare the restored quotes with your source records.

The browser tool and spreadsheet workbooks do not synchronize. Keep workbook copies separately, and label your saved files so you can tell which records belong to each workflow.
